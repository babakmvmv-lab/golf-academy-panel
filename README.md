# panel.puttclub.ir — پنل اعضا

برنامهٔ کامل پنل اعضا (همان مونولیت ریپوی اصلی) مستقیم روی `panel.puttclub.ir` سرو می‌شود.
داده‌ها از همان ابر مشترک (Supabase) همگام می‌شوند.

- `index.html` = نسخهٔ ساخته‌شدهٔ `GolfAcademy_PRO.html` از ریپوی `golf-academy-pro`
- گردش‌کار «Sync app from main repo» هر روز (و به‌صورت دستی) برنامه و فایل‌های جانبی را از ریپوی اصلی به‌روز می‌کند.
- DNS: CNAME با نام `panel` و مقصد `babakmvmv-lab.github.io` (مدیریت در deSEC).
