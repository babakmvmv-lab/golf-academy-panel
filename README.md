# panel.puttclub.ir — پنل اعضا

برنامهٔ کامل پنل اعضا (همان مونولیت ریپوی اصلی) مستقیم روی `panel.puttclub.ir` سرو می‌شود.
داده‌ها از همان ابر مشترک (Supabase) همگام می‌شوند.

- `index.html` = نسخهٔ ساخته‌شدهٔ `GolfAcademy_PRO.html` از ریپوی `golf-academy-pro`
- گردش‌کار «Sync app from main repo» هر روز (و به‌صورت دستی) برنامه و فایل‌های جانبی را از ریپوی اصلی به‌روز می‌کند.
- DNS: CNAME با نام `panel` و مقصد `babakmvmv-lab.github.io` (مدیریت در deSEC).

## پنل اعضا = فقط «داشبورد» (مدیریت → adminpanel.puttclub.ir)

مدیریت آکادمی به **adminpanel.puttclub.ir** منتقل شده است. همان کد (`golf-academy-pro`) و همان ابر (`ga_store` / `ga-sync`)، فقط در کنسول ادمین.

- `members-only/moved.json`: فهرست بخش‌هایی که از این پنل برداشته شده‌اند. شناسه‌ها: صفحه‌ها `users`، `subs`، `settings`، `backup`، `messages`، `mgmt` و تب‌های «پنل مدیریت» به‌صورت `mgmt:<tab>` (مثلاً `mgmt:players`). وقتی هر ۱۷ تب منتقل شوند، خودِ «پنل مدیریت» هم برداشته می‌شود؛ وقتی همهٔ آیتم‌های گروه «مدیریت» منتقل شوند، عنوان گروه هم پنهان می‌شود.
- هر آیتم فقط **بعد از** این‌که در ادمین‌پنل با همان داده‌ها آزموده و یکسان دیده شد، با یک کامیت جداگانه به این فهرست اضافه شده است (بازگرداندن یک آیتم = revert همان کامیت).
- `members-only/guard.js` + `inject.py`: در گردش‌کار sync، بعد از ساخت `index.html`، اسکریپت کوچکی پیش از اسکریپت‌های برنامه تزریق می‌شود که فقط همین بخش‌ها را از منو، تب‌ها، میان‌برها، آدرس مستقیم (`#users`…) و دکمهٔ Back برمی‌دارد؛ اگر تب فعالِ «پنل مدیریت» منتقل شده باشد، اولین تب باقی‌مانده باز می‌شود. کد برنامه دست نمی‌خورد، داده‌ها همان ابر مشترک‌اند و رفتار اعضا دقیقاً مثل قبل است.
- بازگرداندن یک بخش به پنل = حذف شناسه‌اش از `moved.json` و اجرای `python3 members-only/inject.py index.html` (یا اجرای sync).
- `admin-bridge.html`: یوزرها، ورود قدیمی بازیکنان و نسخه‌های «پشتیبان آکادمی» طبق طراحی برنامه فقط روی همین دستگاه‌اند و به ابر نمی‌روند. ادمین‌پنل این صفحه را در iframe مخفی باز می‌کند تا روی همان دستگاه همان فهرستی را مدیریت کند که این پنل برای ورود استفاده می‌کند. فقط به `https://adminpanel.puttclub.ir` جواب می‌دهد، فقط همین سه کلید، و هیچ درخواست شبکه‌ای ندارد.
